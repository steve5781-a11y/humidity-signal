    도움말

    색과 모양의 뜻
    ▼ 노랑 낮음 = 건조(증산 과다, 잎 끝 마름 주의) · ● 초록 적정 · ▲ 빨강 높음 = 과습(잿빛곰팡이병 위험, 환기 필요). 같은 뜻이 글자로도 표시됩니다.
    왜 경계에서 바로 색이 안 바뀌나요?
    85 %에서 빨강이 된 뒤에는 83 % 이하로 내려가야 초록으로 돌아갑니다(낮음 쪽은 60 % / 62 %). 센서 값이 경계에서 흔들릴 때 신호가 깜빡이지 않게 하는 여유 구간입니다.
    부저는 언제 울리나요?
    적정에서 낮음으로 바뀌면 2번, 높음으로 바뀌면 3번 짧게 울립니다. 같은 상태가 이어지면 다시 울리지 않고, 적정일 때는 울리지 않습니다. "보드 부저" 버튼으로 끌 수 있고, "화면 알림음"은 이 PC에서만 나는 소리라 보드 부저와 따로 켜고 끕니다.
    "값 없음"과 0 %는 다릅니다
    센서를 읽지 못하면 0이 아니라 "값 없음"으로 표시하고 보드 신호등은 파랑으로 켭니다. 3초 넘게 보드 소식이 없으면 "응답 없음"을 표시하고 설정 버튼을 잠급니다. 이때 LED가 꺼졌다고 가정하지 않습니다.
    연결이 안 될 때
    데이터용 USB 케이블인지, 보드에 P07 코드가 올라가 있는지, Arduino 시리얼 모니터가 닫혀 있는지 확인하세요. USB 직접 연결은 Chrome·Edge에서만 됩니다. 다른 브라우저는 PC 연결 프로그램(브리지)을 쓰세요.
    측정 정확도
    DHT11은 습도 ±5 %, 온도 ±2 °C 정도의 오차가 있는 교육용 센서입니다. 실제 재배 판단에는 검증된 센서를 쓰세요.
