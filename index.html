딸기 하우스 습도 신호등

딸기 하우스의 습도가 관리 범위(60–85 %)를 벗어났는지 보드의 불빛·소리와 웹 대시보드로 바로 알려 줍니다. 멀리서는 색과 소리로, 가까이서는 숫자와 그래프로 확인합니다.

누가, 무엇을, 어디서

사용자 (가정)

딸기 하우스를 돌보는 관리자와 실습생. 작업 중이라 화면을 오래 볼 수 없고, 색을 구별하기 어려운 사람도 있을 수 있습니다.

과업

  • 지금 습도가 낮음·적정·높음 중 무엇인지 몇 초 안에 판단
  • 벗어났을 때 바로 조치 (건조 → 관수·차광, 과습 → 환기)
  • 작물·계절에 맞게 기준값을 바꾸기

사용 맥락

하우스(또는 교실) 안, 보드 옆의 PC 한 대. 주변이 시끄러울 수 있고 USB 전원만 씁니다. 대시보드는 Chrome·Edge에서 USB로 직접 연결합니다.

페이지 안내

대시보드

지금 습도·온도와 각각의 상태, 10분 그래프 2개, 기준값·밝기·신호등·부저 설정, CSV 저장(온도·습도 골라서).

습도 경보는 짧게, 온도 경보는 길게 울려 소리로 구별합니다. 색만으로 뜻을 전하지 않도록 모양(▼●▲)과 글자, 부저 횟수를 함께 씁니다. 같은 파랑이라도 계속 켜져 있으면 건조, 깜빡이면 센서 확인입니다. 경계에서 깜빡이지 않도록 2 %씩 여유를 둡니다(85 %에서 빨강 → 83 % 이하에서 초록).

처음 사용하는 순서

  1. 배선 — 회로도를 따라 연결합니다. USB를 뽑고 작업하세요.
  2. 보드 코드 올리기 — Arduino IDE에서 firmware/P07/P07.ino를 열고 보드 Arduino Uno로 업로드합니다. 라이브러리: DHT sensor library 1.4.7, Adafruit Unified Sensor 1.1.15, LiquidCrystal I2C 1.1.2.
  3. 대시보드 연결 — Chrome 또는 Edge로 대시보드를 열고 「연결하기」 → 보드 포트를 고릅니다. 시리얼 모니터는 닫아 두세요.
  4. 확인 — 지금 습도와 상태가 보이고, 보드 LED 색과 LCD 글자가 같은 상태를 가리키는지 봅니다. 보드가 없으면 연결 방식에서 「시뮬레이션」을 고르면 화면을 연습할 수 있습니다.

확인한 것과 못 한 것

실물로 확인함 (2026-10-29)

  • DHT11 측정값 수신 (습도 52–58 %, 온도 약 27 °C, 실패 0회)
  • 상태별 LED 색: 적정 초록, 높음 빨강, 낮음 파랑 (건조 = 파랑은 2026-10-29 변경 후 보드 출력값으로 확인)
  • 부저: 높음 3번·낮음 2번, 적정일 때 조용함, 소리 크기 적당함
  • LCD 숫자·상태 글자 표시, 잘못된 기준값(낮음 ≥ 높음) 거절

아직 확인하지 못함

  • 실제 딸기 하우스 환경(고습·장시간)에서의 동작
  • 화면 낭독기(NVDA·내레이터)로 전체 사용
  • 부저 1kΩ 저항을 넣은 뒤의 소리 크기 (배선 변경 후 다시 확인 필요)

교육용 시제품입니다. DHT11은 습도 ±5 %, 온도 ±2 °C 오차가 있어 실제 재배 판단에는 검증된 센서를 쓰세요.
