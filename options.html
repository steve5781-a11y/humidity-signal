부품·서비스 옵션 추천

강의 키트(UNO 호환 보드와 센서·출력·표시 부품)만으로 만들 수 있는 서비스를 7가지로 정리하고, 같은 기준으로 비교했습니다. 맨 아래에 이 프로젝트가 1번을 고른 이유가 있습니다.

키트에서 쓸 수 있는 부품

입력·센서

DHT11 온습도, 조도 CdS, 10kΩ 가변저항, 택트 스위치, 기울기 스위치, 수위 센서, 소리 감지 모듈, LM35DZ 온도, 조이스틱, 4×4 키패드, 적외선 리모컨·수신부, RFID RC522, 화염 감지 소자

출력

빨강·노랑·초록 LED, RGB LED 모듈(공통 −), 2핀 부저, SG90 서보, 28BYJ-48 스텝 모터 + ULN2003, 1채널 릴레이

표시·시간

LCD1602 I2C, 1자리·4자리 FND, 74HC595, 8×8 도트매트릭스, DS1302 RTC

서보·스텝 모터는 별도의 안정된 5V 전원이 필요한데 키트 구성표에 없습니다. 능동형·모델 미상 부저나 화염 감지 소자처럼 정격을 모르는 부품은 GPIO에 바로 연결하지 않습니다(강의 안전 수칙).

추천 옵션 7가지

선택함

1. 딸기 하우스 습도 신호등

사용자 하우스 관리자 · 문제 습도가 벗어난 걸 늦게 알아챔

부품 DHT11, RGB LED, 부저, LCD1602 I2C

대시보드 습도·온도·상태, 10분 그래프, 기준값·밝기·부저 설정

강의 옵션 B

2. 작업실 환경판

사용자 공방·작업실 이용자 · 문제 덥고 어두운데 모르고 오래 작업함

부품 DHT11, 조도 CdS + 10kΩ, LCD, LED

대시보드 온도·습도·밝기 3가지와 "쉬세요/환기하세요" 안내

강의 옵션 A

3. 집중 공간 자동 조명

사용자 공부하는 학생 · 문제 어두워져도 조명을 늦게 켬

부품 조도 CdS, 가변저항(원하는 밝기), RGB LED

대시보드 현재 밝기, 자동/수동 전환, 켜짐·꺼짐 두 기준값

4. 화분 물 부족 알리미

사용자 화분을 자주 잊는 사람 · 문제 물 주는 때를 놓침

부품 수위 센서, 부저, 노랑·초록 LED, LCD

대시보드 수위 단계, 마지막으로 물 준 시각

수위 센서는 계속 전원을 주면 부식되므로 잴 때만 켭니다.

5. 교실 소음 신호등

사용자 교사·학생 · 문제 시끄러워지는 걸 말로만 알림

부품 소리 감지 모듈(AO), RGB LED, 4자리 FND

대시보드 소음 단계, 시끄러웠던 시간 기록

어려움

6. RFID 출입 기록판

사용자 동아리방 관리자 · 문제 누가 언제 왔는지 모름

부품 RC522 + 카드, DS1302 RTC, LCD, 부저

대시보드 출입 목록, 등록 카드 관리

RC522는 3.3V 부품이라 신호선마다 분압 저항이 필요합니다.

외부 전원 필요

7. 키패드 잠금 상자

사용자 사물함 사용자 · 문제 열쇠를 잃어버림

부품 4×4 키패드, LCD, SG90 서보

대시보드 잠김 상태, 틀린 시도 횟수

서보용 별도 5V 전원이 키트에 없어 지금은 보류합니다.

1번을 고른 이유

  • 문제가 분명합니다. 딸기는 습도가 높으면 잿빛곰팡이병, 낮으면 잎 끝 마름이 생깁니다. "범위를 벗어났는가"라는 한 가지 질문에 답하면 됩니다.
  • 입력 2개(습도·온도)와 출력 3가지(RGB·부저·LCD)를 키트와 USB 전원만으로 만들 수 있습니다.
  • 상태가 4가지로 딱 나뉩니다(낮음·적정·높음·값 없음). 색·모양·글자·소리로 같은 뜻을 여러 번 전할 수 있어 접근성 설계를 보여 주기 좋습니다.
  • 멀리서도, 가까이서도 쓸 수 있습니다. 작업 중에는 불빛과 부저로, PC 앞에서는 그래프로 추이를 봅니다.
