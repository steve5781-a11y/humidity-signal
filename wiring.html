Smart farm · Arduino UNO · 회로 P07 (제안)

딸기 하우스 습도 신호등 · 한 선씩 연결

DHT11로 습도를 재서 LCD에 숫자와 상태를 띄우고, RGB LED로 낮음은 파랑, 적정은 초록, 높음은 빨강을 켭니다. 낮음·높음으로 바뀌면 부저가 짧게 울립니다(낮음 2번, 높음 3번). 같은 값과 색을 웹 대시보드에도 보여 줍니다.

  • UNO 호환 R3 1대
  • USB 전원만 사용
  • 암–수 점퍼 11개 (키트 10개 + 1개 추가)
  • 수–수 점퍼 15개
  • 시리얼 115200 · JSON
연결 전에 확인하세요

암–수 점퍼가 키트 수량보다 1개 더 필요합니다. 강사님께 1개를 더 받거나, 받기 전까지는 LCD를 빼고 RGB와 대시보드로만 시험합니다(이때 7개). RGB 모듈이 공통 −형인지 먼저 확인하세요. 공통 +형이면 연결과 코드가 달라집니다. 부저는 능동형이라 D8에 바로 연결하지 않고 반드시 1kΩ 저항을 거칩니다.

한 단계씩 연결하세요

연두색 띠 한 개가 같은 금속판(구멍 5개)입니다. 가운데 홈 건너편은 분리돼 있습니다. 주황 선이 이번 단계이고 앞 단계는 원래 색으로 남습니다. 오른쪽 모듈 카드는 핀 이름을 펼친 그림이며 실제 커넥터의 좌우 순서가 아닙니다. 작은 화면에서는 그림을 가로로 이동하세요.

색이 바뀌는 규칙

습도 기준은 딸기 초기값입니다. 기준값을 확인한 뒤 대시보드에서 바꿀 수 있습니다. 경계값 근처에서 색이 깜빡이듯 바뀌지 않도록 바뀌는 방향마다 2%씩 여유(히스테리시스)를 둡니다.

  • 여유 구간: 적정 → 높음은 85 %에서, 높음 → 적정은 83 % 이하에서 바뀝니다. 낮음 쪽도 60 % / 62 %로 같은 방식입니다.
  • LCD1602는 한글을 바로 표시하지 못해 영문으로 씁니다. 1번째 줄 예: RH 72% T 24C
  • 색만으로 상태를 전달하지 않습니다. LCD와 대시보드에 "낮음 / 적정 / 높음" 글자를 함께 띄워 색약인 사람도 읽을 수 있게 합니다(WCAG 1.4.1).
  • 교실 시연: 센서에 입김을 불면 빨강, 마른 바람(부채·드라이어 찬바람)을 쐬면 파랑 쪽으로 움직입니다. 교실 습도는 대개 낮아서 처음에는 파랑이 켜지고 부저가 2번 울릴 수 있습니다.

코드와 보드 핀

코드 이름UNO 핀방향

RGB는 PWM 핀(D5·D6·D9), 부저는 D8입니다. 부저 소리 크기 조절에 Timer2를 써서 D3·D11의 PWM은 쓰지 않습니다. 비워 두는 핀: D0·D1(USB 시리얼), D2, D3, D7, D10–D13, A0–A3.

준비물

  • DHT11 모듈 1, RGB LED 모듈 1, LCD1602 I2C 1, 2핀 능동형 부저 1
  • 1kΩ 4개 (RGB 채널마다 1개 + 부저 1개)
  • 암–수 점퍼 11개 (키트 10개 + 1개 추가), 수–수 점퍼 15개

라이브러리: DHT sensor library 1.4.7, Adafruit Unified Sensor 1.1.15, LiquidCrystal I2C 1.1.2.
